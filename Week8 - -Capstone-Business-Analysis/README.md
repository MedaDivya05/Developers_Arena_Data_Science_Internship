# 📊 Week 8 - Capstone Project: Real World Business Analysis

## 📌 Project Overview

This project was completed as part of Week 8 of the Data Science Online Internship at The Developers Arena.

The objective of this capstone project is to perform an end-to-end real world business analysis using customer churn and sales datasets. The project focuses on understanding customer behavior, identifying churn patterns, analyzing business performance, and providing data-driven recommendations for improving customer retention and business growth.

This project combines all the concepts learned throughout the internship including:

- Data Cleaning
- Exploratory Data Analysis
- Statistical Analysis
- Correlation Analysis
- Data Visualization
- Business Insight Generation
- Predictive Modeling
- Business Recommendation Planning

The project demonstrates a complete business analytics workflow from raw data to actionable insights.
