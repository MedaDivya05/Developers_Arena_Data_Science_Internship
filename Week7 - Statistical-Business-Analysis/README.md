# 📊 Week 7 - Statistical Business Analysis

## 📌 Project Overview

This project was completed as part of Week 7 of the Data Science Online Internship at The Developers Arena.

The objective of this project is to apply statistical concepts to business datasets using Python. The project focuses on descriptive statistics, correlation analysis, hypothesis testing, confidence intervals, and regression analysis.

The analysis helps identify statistical relationships between business variables and supports data-driven decision making.

---

# 🎯 Objectives

- Calculate descriptive statistics
- Analyze data distributions
- Perform hypothesis testing
- Conduct correlation analysis
- Calculate confidence intervals
- Perform regression analysis
- Generate business insights
